# Steady30 website

Static public website for `steady30.online`.

## Pages

- `/` — landing page
- `/privacy/` — Google Play privacy-policy URL
- `/terms/`
- `/safety/`
- `/delete-account/`
- `/community-guidelines/`

## Vercel

Import this repository into Vercel as a static site. No build command or framework preset is required. Attach `steady30.online` and ensure these pages are reachable over HTTPS.

Before going live, configure mail forwarding for `support@steady30.online`, then set the same address and all public URLs in the app's production environment.

The policy copy is an operational draft based on the app's current behaviour, not legal advice. Have it reviewed before a production launch.
